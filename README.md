# 🧊 인성이네 냉장고
냉장실·냉동실 재료를 2열로 한눈에 보고, 소비기한이 임박한 것부터 챙기고, 지금 있는 재료로 바로 되는 **아침·점심·저녁 간단 식단**까지 보는 **모바일 전용 조회 화면**이에요.

👉 https://jongheeyi-crypto.github.io/fridge/

- 📱 폰에서 열어 홈 화면에 추가하면 앱처럼 써요.
- 👀 **보기 전용** — 로그인도, 입력도 없어요. 링크만 있으면 누구나 같은 화면을 봅니다.
- 🔒 이름·전화번호·집 주소 같은 개인정보는 넣지 않아요. 식재료와 식단만 담습니다.
- 📅 **없는 소비기한은 지어내지 않아요.** 날짜를 모르는 재료는 그냥 `냉장 보관` / `냉동 보관` 배지로만 표시됩니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 🏠 전체 보기 | 요약 배지 + 오늘의 아침·저녁 추천 + 냉장실 + 냉동실 (모두 2열 그리드) |
| 📅 주간 식단 | 7일 냉장고 파먹기 플랜 · 끼니마다 ⭕ 먹음 / ❌ 패스 체크 + 자동 미루기 |
| ❄️ 냉장실 | 냉장 재료 |
| 🧊 냉동실 | 냉동 재료 |
| 🍳 간단 식단 | 🏫 라이즈 점심 식단 연동 배너 + 🌅 아침(인성이 전용) / 🥗 엄마 점심(혼밥 1인분) / 🌙 저녁(세 가족) / 🥗 어른 샐러드 |
| 🛒 장보기 | 떨어져 가는 것 / 필요한 것 |

재료 검색과 카테고리 필터(밀키트 / 생선·고기 / 유제품·빵 / 채소·과일 / 반찬·소스 / 아이 맞춤)를 쓸 수 있어요.

### 📅 주간 식단의 ⭕/❌ 체크

- 끼니 카드(아침·점심·저녁)의 **⭕ 먹음 / ❌ 패스**를 누르면 같은 버튼을 다시 눌러 해제할 수 있어요. 체크는 이 브라우저의 `localStorage`(`insung_fridge_ox_v1`, 주간 플랜 `startDate`별)에만 저장되고 `data.json`은 건드리지 않습니다.
- **❌ 패스**한 끼니의 메뉴는 같은 코스(아침→아침, 점심→점심, 저녁→저녁)의 뒤 날짜로 자동 순연돼요. 이미 `⭕ 먹음`·`❌ 패스`·`data.json`의 `skipped`인 자리는 건너뛰고, 평일 아침·저녁은 그날 라이즈 점심 `avoidTags`와 겹치면 그날을 건너뜁니다(매운 저녁은 `kidMenu` 기준). 밀려 들어온 메뉴에는 `↪️ 11/17(화) 저녁에서 미룸` 배지가 붙고, 일요일 뒤로 남은 메뉴는 `📦 다음 주로 미뤄진 메뉴`에 모입니다.
- 체크가 하나라도 있으면 **📋 피클에 보낼 내용 복사**와 **↺ 초기화** 버튼이 뜹니다. 복사한 문장을 피클에게 보내면 남편 화면·냉장고 재고도 같이 맞춰요.

## 데이터는 `data.json` 한 곳에서만 고칩니다

`index.html`·`styles.css`·`app.js`는 화면만 담당하고, 내용은 전부 `data.json`에 있어요.

```jsonc
{
  "isSample": false,                          // 예시 데이터면 true → 화면 위에 안내 배너가 뜸
  "updatedAt": "2026-11-15T17:02:00+09:00",   // 화면 상단 "마지막 업데이트" (KST)

  "fridge": [                                 // ❄️ 냉장실
    {
      "name": "[일미어담] 고등어구이 200g",
      "emoji": "🐟",
      "qty": "1개",
      "category": "생선·고기",                 // 필터에 쓰는 이름
      "expiryDate": null,                     // YYYY-MM-DD. 모르면 반드시 null
      "arriving": "2026-11-16",                // (선택) 주문 도착일 → 카드에 📦 내일 도착 배지, 지나면 자동으로 사라짐
      "memo": "에어프라이어 6분 · 가시 주의"    // 선택
    }
  ],

  "freezer": [ /* 🧊 냉동실 — 같은 형식 */ ],

  "meals": [                                  // 🍳 간단 식단
    {
      "title": "우유 식빵 햄토스트 & 사과",
      "emoji": "🥪",
      "course": "breakfast",                  // breakfast(인성이 아침) | lunch(엄마 점심 혼밥) | dinner(세 가족 저녁) | salad(어른 샐러드)
      "who": "👶 인성이 전용",                 // 👶 인성이 전용 / 👨‍👩‍👦 3가족 함께 / 🌶️ 어른 매운메뉴 + 👶 인성이 별도 / 🥗 어른용
      "time": "5분",
      "difficulty": "★☆☆ 초간단",
      "uses": ["우유 식빵", "ALL 얇은 샌드위치햄", "감홍 사과", "전용목장우유"],
      "keywords": ["빵", "사과", "우유", "햄"],
      "avoidTags": ["빵", "사과", "과일"],      // 이 날 점심 식단과 겹치면 피할 태그
      "memo": "선택 메모",
      "kidMenu": {                             // (선택) 매운 저녁일 때 인성이 별도 메뉴
        "title": "임연수구이 + 2컵두부 부침",
        "uses": ["임연수구이", "국산콩 2컵두부"],
        "avoidTags": ["두부", "생선"]          // 이 태그도 점심 식단과 따로 대조해요
      },
      "steps": ["식빵 두 장에 햄 올려 2분씩", "사과·우유 곁들이면 끝"]
    }
  ],

  "lunchMenu": {                              // 🍱 인성이 유치원 점심 식단표 (라이즈 목동원 11월)
    "active": true,
    "schoolName": "라이즈 11월 점심 식단",
    "schedule": [
      {
        "date": "2026-11-16",
        "dayLabel": "월",
        "snack": "우유",
        "items": ["흑미밥", "어묵국", "치킨너겟", "청경채나물무침", "유아김치"],
        "avoidTags": ["어묵", "치킨", "닭"]        // 이 날 점심과 겹치면 피할 태그
      }
    ]
  },

  "shopping": [                               // 🛒 장보기 (비어 있으면 친절한 빈 화면)
    { "name": "우유", "emoji": "🥛", "reason": "곧 떨어져요 · 마지막 1팩" }
  ]
}
```

### 규칙 몇 가지

- `category`는 `data.json`에 적힌 이름 그대로 필터 칩이 됩니다. 지금 쓰는 값: `밀키트`, `생선·고기`, `유제품·빵`, `채소·과일`, `반찬·소스`, `아이 맞춤`
- `meals[].uses`는 재료 `name`과 글자가 같으면 ✅, 없으면 🛒 (부분 일치도 인정: `우유 식빵` → `클래식 우유 식빵 420g`). 아직 도착 전인 재료는 📦로 표시됩니다.
- **`expiryDate`가 `null`이면 날짜를 만들지 않습니다.** 냉장은 초록빛 `냉장 보관`, 냉동은 파란빛 `냉동 보관` 배지만 뜨고, 임박 개수에도 들어가지 않아요.
- 날짜가 있는 재료만 D-day가 계산됩니다 — `D-day`·`D-1` 빨간 펄스 · `D-2~3` 주황 · `D-4` 이상 민트 · 지난 날짜 `D+n`
- **식단은 아침·점심·저녁을 따로 짱니다**: `course: breakfast`는 인성이 전용 아침(어른 샐러드는 여기 못 들어옴), `course: lunch`는 엄마가 집에서 혼자 먹는 점심(1인분이라 3가족 저녁과 분리, 예: 컬리플라워볶음밥·하림버팔로핫봉), `course: dinner`는 3가족 저녁, `course: salad`는 맨 아래 어른 간편 샐러드 섹션이에요.
- 매운 저녁은 `kidMenu`에 인성이 별도 메뉴를 넣으면 카드 안에 점선 박스로 따로 보입니다. 점심 대조는 **어른 메뉴와 인성이 별도 메뉴 둘 다** 확인해요.
- **`priority: 1`은 ‘냉장고 파먹기 1순위’**: 기존에 있던 재료와 그 재료를 쓰는 식단에 `priority: 1`을 달면 카드에 `🔥 우선 소진` / `🔥 냉장고 파먹기 1순위` 배지가 붙고, 냉동실 맨 앞(도착 예정 재료보다 먼저)으로 올라와요. 식단은 **점심과 안 겹치면서 `priority: 1`인 메뉴 → 안 겹치는 메뉴 → 겹치는 메뉴** 순서로 보여줍니다.
- **점심 식단 연동**: `lunchMenu.schedule`에서 오늘(급식일) 또는 가장 가까운 다음 급식일을 자동으로 골라 배너에 보여줘요. 각 메뉴의 `avoidTags`가 그날 점심 `items`·`avoidTags`와 겹치면 `⚠️ 11/16(월) 점심 ‘어묵국’과 겹침`처럼 겹치는 메뉴를 집어서 표시하고 목록 뒤로 보내며, 안 겹치는 메뉴에는 `✨ 점심과 안 겹쳐요`가 붙어 위로 올라옵니다. `간단 식단` 배너의 `11월 식단표 전체 보기`를 누르면 그 달 식단표를 다 볼 수 있어요.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 그대로 서빙합니다. 빌드 과정 없음, 상대 경로(`./data.json`)만 사용.

```bash
git add -A && git commit -m "냉장고 업데이트" && git push origin main
```
