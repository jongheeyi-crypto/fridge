# 🧊 인성이네 냉장고
냉장실·냉동실·실온 재료를 2열로 한눈에 보고, 소비기한이 임박한 것부터 챙기고, 지금 있는 재료로 바로 되는 **아침·점심·저녁 간단 식단**까지 보는 **모바일 전용 조회 화면**이에요.

👉 https://jongheeyi-crypto.github.io/fridge/

- 📱 폰에서 열어 홈 화면에 추가하면 앱처럼 써요.
- 👀 **보기 전용** — 로그인도, 입력도 없어요. 링크만 있으면 누구나 같은 화면을 봅니다.
- 🔒 이름·전화번호·집 주소 같은 개인정보는 넣지 않아요. 식재료와 식단만 담습니다.
- 📅 **없는 소비기한은 지어내지 않아요.** 날짜를 모르는 재료는 그냥 `냉장 보관` / `냉동 보관` / `실온 보관` 배지로만 표시됩니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 🏠 전체 보기 | 🍳 오늘 뭐 먹지?(주간 식단 연동) + 📅 주간 식단 티저 + 냉장실 + 냉동실 + 🧺 실온 (2열 그리드) + 🧂 우리 집 조미료·부재료(맨 아래 · 읽기 전용 · 기본 접힘) |
| 📅 주간 식단 | 7일 냉장고 파먹기 플랜 · 끼니마다 ⭕ 먹음 / ❌ 패스 체크 + 자동 미루기 |
| ❄️ 냉장실 | 냉장 재료 |
| 🧊 냉동실 | 냉동 재료 |
| 🧺 실온 | 실온(찬장) 재료 — 냉장·냉동과 똑같은 재고 카드 레이아웃 |
| 🍳 간단 식단 | 🏫 라이즈 점심 식단 연동 배너 + 🌅 아침(인성이 전용) / 🥗 엄마 점심(혼밥 1인분) / 🌙 저녁(세 가족) / 🥗 어른 샐러드 |
| 🛒 장보기 | 떨어져 가는 것 / 필요한 것 |

### 🍳 오늘 뭐 먹지? = 주간 식단 연동

`전체 보기` 맨 위의 **🍳 오늘 뭐 먹지?** 카드는 `meals` 추천이 아니라 **`weekPlan`에 선정된 그날 식단**을 그대로 보여줘요.

- KST(`Asia/Seoul`) 기준 오늘 날짜로 `weekPlan.days`에서 그날을 찾고, 주간 시작 전이면 `weekPlan.days[0]`, 주간이 끝났으면 마지막 날을 골라 배지로 알려줘요(`다가오는 11/16(월) 식단` / `오늘 11/16(월) 식단` / `지난 11/22(일) 식단`).
- 🌅 인성이 아침 / 🥗 엄마 점심(주말엔 🍱 주말 점심) / 🌙 세 가족 저녁을 콤팩트한 세 줄로 보여주고, 시간·👶 인성이 별도 메뉴·`skipped`(⏭️ 외출·패스)까지 같이 나와요.
- **`📅 주간 식단에서 O/X 체크하기 →`** 버튼으로 바로 `주간 식단` 탭에 가서 체크할 수 있어요.
- `주간 식단`에서 누른 ⭕/❌(`insung_fridge_ox_v1`)는 홈 카드에도 그대로 반영돼요 — 주간 식단과 **같은 `computeWeekView` 순연 엔진**을 다시 돌려서, 밀린 결과 기준으로 `❌ 미룸 → 11/18(수) 저녁으로`·`↪️ 11/17(화) 저녁에서` 배지가 붙어요.
- `weekPlan`이 없거나 검색 중일 때만 예전 `meals` 추천으로 폴백해요.

### 🧺 실온 재고 (냉장·냉동과 같은 레이아웃)

실온(찬장) 식품은 `data.json`의 **최상위 `roomTemp[]`** 배열에 `fridge`·`freezer`와 **똑같은 스키마**(`name`·`emoji`·`qty`·`category`·`expiryDate`·`memo`)로 있어요. 지금은 **16종**(즉석밥·국·간편식 6 / 인성이용·어린이 반찬 4 / 통조림·건어물·시리얼 6)이에요.

- **🧺 실온** 탭이 따로 있고, `전체 보기`에서도 `냉장실 (19개)` → `냉동실 (35개)` → `🧺 실온 (16개)` 순서로 **같은 2열 카드 그리드**로 나와요. 상단 배지도 `냉장 19 · 냉동 35 · 실온 16`.
- `expiryDate`가 없으니 카드에는 따뜻한 살구빛 **`실온 보관`** 배지(`.dday.keep-room`)가 붙어요.
- 검색·카테고리 칩도 냉장·냉동과 똑같이 동작하고(`밀키트 / 생선·고기 / 유제품·빵 / 채소·과일 / 반찬·소스 / 아이 맞춤`), 실온 재료도 식단 카드 재료 칩에서 `✅`(있음)으로 쳐요(`inStock()`이 `allItems()`로 `roomTemp`를 함께 읽음).

### 🧂 우리 집 조미료 · 부재료 (읽기 전용)

`전체 보기` **맨 아래**(실온 섹션 아래)의 **🧂 우리 집 조미료 · 부재료 (37종)** 섹션은 **이제 체크하지 않아요.** 기본은 접힌 컴팩트 요약 — `보유 37종 · 없는 것 1종(쌈장)` 한 줄과 **목록 보기 ▾** 버튼만 보여요. 버튼을 누르면 조미료 4그룹(장류·간장 / 소스·기름 / 가루·단맛 / 육수·부재료)의 **보유 조미료가 체크박스 없는 정적 칩**으로 펼쳐지고, 맨 아래 `없는 것` 줄에 `미보유: 쌈장`만 흐린 점선 태그로 표시돼요. `접기 ▴`로 다시 접혀요.

- 예전 `☑️/⬜` 체크박스, `☑️ 전체 선택`, `↺ 처음 값으로`, `📋 체크한 조미료 복사해서 피클에 보내기`, `localStorage`(`insung_fridge_pantry_v1`) 저장은 **모두 없앴어요.**
- `pantry`는 조미료 4개 그룹 **38개**(`쌈장`만 `checked: false` → 보유 37 / 미보유 1)이고, `checked`는 **보유/미보유 표시로만** 읽어요. **냉장 19 · 냉동 35 · 실온 16 재고 숫자에는 들어가지 않아요.**
- 실온 식품은 이 섹션에서 빠져 `roomTemp[]`로 옮겼으니, 조미료 섹션에는 `pantry.groups`만 남아요.

재료 검색과 카테고리 필터(밀키트 / 생선·고기 / 유제품·빵 / 채소·과일 / 반찬·소스 / 아이 맞춤)를 쓸 수 있어요.

### 📅 주간 식단의 ⭕/❌ 체크

- 끼니 카드(아침·점심·저녁)의 **⭕ 먹음 / ❌ 패스**를 누르면 같은 버튼을 다시 눌러 해제할 수 있어요. 체크는 이 브라우저의 `localStorage`(`insung_fridge_ox_v1`, 주간 플랜 `startDate`별)에만 저장되고 `data.json`은 건드리지 않습니다.
- **❌ 패스**한 끼니의 메뉴는 같은 코스(아침→아침, 점심→점심, 저녁→저녁)의 뒤 날짜로 자동 순연돼요. 이미 `⭕ 먹음`·`❌ 패스`·`data.json`의 `skipped`인 자리는 건너뛰고, 평일 아침·저녁은 그날 라이즈 점심 `avoidTags`와 겹치면 그날을 건너뜁니다(매운 저녁은 `kidMenu` 기준). 밀려 들어온 메뉴에는 `↪️ 11/17(화) 저녁에서 미룸` 배지가 붙고, 일요일 뒤로 남은 메뉴는 `📦 다음 주로 미뤄진 메뉴`에 모입니다.
- 체크가 하나라도 있으면 **📋 피클에 보낼 내용 복사**와 **↺ 초기화** 버튼이 뜹니다. 복사한 문장을 피클에게 보내면 남편 화면·냉장고 재고도 같이 맞춰요.

### 규칙 몇 가지

- `category`는 `data.json`에 적힌 이름 그대로 필터 칩이 됩니다. 지금 쓰는 값: `밀키트`, `생선·고기`, `유제품·빵`, `채소·과일`, `반찬·소스`, `아이 맞춤`
- `meals[].uses`는 재료 `name`과 글자가 같으면 ✅, 없으면 🛒 (부분 일치도 인정: `우유 식빵` → `클래식 우유 식빵 420g`). 아직 도착 전인 재료는 📦로 표시됩니다. `roomTemp`(실온)에 있는 재료도 ✅로 쳐요.
- **`expiryDate`가 `null`이면 날짜를 만들지 않습니다.** 냉장은 초록빛 `냉장 보관`, 냉동은 파란빛 `냉동 보관`, 실온은 살구빛 `실온 보관` 배지만 뜨고, 임박 개수에도 들어가지 않아요.
- 날짜가 있는 재료만 D-day가 계산됩니다 — `D-day`·`D-1` 빨간 펄스 · `D-2~3` 주황 · `D-4` 이상 민트 · 지난 날짜 `D+n`
- **식단은 아침·점심·저녁을 따로 짱니다**: `course: breakfast`는 인성이 전용 아침(어른 샐러드는 여기 못 들어옴), `course: lunch`는 엄마가 집에서 혼자 먹는 점심(1인분이라 3가족 저녁과 분리, 예: 컬리플라워볶음밥·하림버팔로핫봉), `course: dinner`는 3가족 저녁, `course: salad`는 맨 아래 어른 간편 샐러드 섹션이에요.
- 매운 저녁은 `kidMenu`에 인성이 별도 메뉴를 넣으면 카드 안에 점선 박스로 따로 보입니다. 점심 대조는 **어른 메뉴와 인성이 별도 메뉴 둘 다** 확인해요.
- **`priority: 1`은 ‘냉장고 파먹기 1순위’**: 기존에 있던 재료와 그 재료를 쓰는 식단에 `priority: 1`을 달면 카드에 `🔥 우선 소진` / `🔥 냉장고 파먹기 1순위` 배지가 붙고, 냉동실 맨 앞(도착 예정 재료보다 먼저)으로 올라와요. 식단은 **점심과 안 겹치면서 `priority: 1`인 메뉴 → 안 겹치는 메뉴 → 겹치는 메뉴** 순서로 보여줍니다.
- **점심·오후 간식 연동**: `lunchMenu.schedule`에서 오늘(급식일) 또는 가장 가까운 다음 급식일을 자동으로 골라 배너에 보여줘요. `afternoonSnack`(오후 간식)도 같이 표시하고, 그 간식의 재료 태그를 그날 `avoidTags`에 넣어 두면 아침·저녁 추천과 자동 미루기(❌ 패스)가 점심과 오후 간식을 **한꺼번에** 피해요. 각 메뉴의 `avoidTags`가 그날 점심 `items`·`avoidTags`(오후 간식 포함)와 겹치면 `⚠️ 11/16(월) 점심·오후 간식 ‘어묵국’과 겹침`처럼 겹치는 메뉴를 집어서 표시하고 목록 뒤로 보내며, 안 겹치는 메뉴에는 `✨ 점심과 안 겹쳐요`가 붙어 위로 올라옵니다. `간단 식단` 배너의 `11월 식단표 전체 보기`를 누르면 그 달 식단표를 다 볼 수 있어요.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 그대로 서빙합니다. 빌드 과정 없음, 상대 경로(`./data.json`)만 사용.

```bash
git add -A && git commit -m "냉장고 업데이트" && git push origin main
```
