# 🧊 우리집 냉장고

냉장실·냉동실 재료를 한눈에 보고, 소비기한이 임박한 것부터 챙기고, 지금 있는 재료로 바로 되는 간단 식단까지 보는 **모바일 전용 조회 화면**이에요.

👉 https://jongheeyi-crypto.github.io/fridge/

- 📱 폰에서 열어 홈 화면에 추가하면 앱처럼 써요.
- 👀 **보기 전용** — 로그인도, 입력도 없어요. 링크만 있으면 누구나 같은 화면을 봅니다.
- 🔒 이름·전화번호·집 주소 같은 개인정보는 넣지 않아요. 식재료와 식단만 담습니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 🏠 전체 보기 | 요약 배지 + 오늘의 간단 식단 + 냉장실 + 냉동실 |
| ❄️ 냉장실 | 냉장 재료 (소비기한 임박한 순) |
| 🧊 냉동실 | 냉동 재료 |
| 🍳 간단 식단 | 있는 재료로 10~15분 안에 되는 메뉴 |
| 🛒 장보기 | 떨어져 가는 것 / 필요한 것 |

재료 검색과 카테고리 필터(밀키트 / 유제품·계란 / 채소·과일 / 고기·해산물 / 반찬·소스 / 아이 간식)를 쓸 수 있어요.

## 데이터는 `data.json` 한 곳에서만 고칩니다

`index.html`·`styles.css`·`app.js`는 화면만 담당하고, 내용은 전부 `data.json`에 있어요. 장보기 캡처나 냉장고 사진을 받으면 이 파일의 배열만 고치면 됩니다.

```jsonc
{
  "isSample": true,                  // 예시 데이터면 true → 화면 위에 안내 배너가 뜸. 실제 데이터로 채우면 false
  "updatedAt": "2026-11-15T16:45:00+09:00",  // 화면 상단 "마지막 업데이트" (KST)
  "sampleNotice": "✨ 예시 화면이에요 · ...",

  "fridge": [                        // ❄️ 냉장실
    {
      "name": "우유",
      "emoji": "🥛",
      "qty": "1팩",
      "category": "유제품·계란",       // 아래 6개 중 하나
      "expiryDate": "2026-11-17",     // YYYY-MM-DD. 모르면 null
      "memo": "990ml · 아이 아침용"    // 선택
    }
  ],

  "freezer": [ /* 🧊 냉동실 — 같은 형식. expiryDate가 null이면 "냉동 보관" 배지 */ ],

  "meals": [                          // 🍳 간단 식단
    {
      "title": "순두부찌개 한 냄비",
      "emoji": "🍲",
      "time": "10분",
      "difficulty": "★☆☆ 초간단",
      "uses": ["순두부찌개 밀키트", "계란", "대파"],  // name과 똑같이 적으면 ✅, 없으면 🛒
      "steps": ["냄비에 물 400ml ...", "7분 끓이고 ..."]   // 1~2줄
    }
  ],

  "shopping": [                       // 🛒 장보기
    { "name": "우유", "emoji": "🥛", "reason": "곧 떨어져요 · 마지막 1팩" }
  ]
}
```

### 규칙 몇 가지

- `category`는 정확히 이 중 하나: `밀키트`, `유제품·계란`, `채소·과일`, `고기·해산물`, `반찬·소스`, `아이 간식`
- D-day는 `expiryDate`와 **오늘 날짜**로 화면에서 자동 계산돼요. 날짜를 고치면 새로고침만 해도 배지·임박 개수가 바뀝니다.
  - `D-day`·`D-1` 빨간 펄스 · `D-2~3` 주황 · `D-4` 이상 민트 · 지난 날짜 `D+n`
- `meals[].uses`는 `fridge`/`freezer`의 `name`과 **글자까지 똑같이** 맞춰야 ✅가 뜹니다.
- 모든 값은 화면에 그대로 출력되니 HTML 태그는 넣지 마세요.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 그대로 서빙합니다. 빌드 과정 없음, 상대 경로(`./data.json`)만 사용.

```bash
git add -A && git commit -m "냉장고 업데이트" && git push origin main
```
